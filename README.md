# 链接打开方式控制器

一个 [Tampermonkey（油猴）](https://www.tampermonkey.net/) 脚本：在任意网页上提供一个**可自由拖动（支持触屏）的全局悬浮按钮**，用来统一控制页面链接的打开方式——当前页面打开、新标签页打开并自动切换、新标签页后台打开。

![version](https://img.shields.io/badge/version-1.0.0-blue) ![license](https://img.shields.io/badge/license-MIT-green) ![platform](https://img.shields.io/badge/platform-Tampermonkey-orange)

## 功能特性

- **三种打开模式，一键切换**
  - `无`：不干预，按网页默认方式打开
  - `新窗并切换`：新标签页打开并立即跳转到新标签（前台）
  - `新窗不切换`：新标签页打开但留在当前页（后台，方便连续浏览多个链接）
- **可拖动悬浮按钮（FAB）**
  - 鼠标与触屏均可拖拽（Pointer Events），自动区分点击与拖动
  - 位置自动裁剪入视口并持久化保存，刷新、重开浏览器都不丢失
- **智能气泡面板（Popover）**
  - 点击悬浮按钮展开，依据视口剩余空间在按钮上/下/左/右自动选位
  - 平滑展开、稳定常显；显示期间不响应滚动与外部点击，不会无故消失
- **个性化外观**
  - 11 款内置图标皮肤，网格缩略图点选即换
  - 面板背景透明度、悬浮按钮尺寸（40–120px）均可调节
  - 所有皮肤图标以 base64 内嵌，离线、跨机器均可用
- **全屏自动隐藏**
  - 浏览器原生全屏（Fullscreen API）自动隐藏，退出后原位恢复
  - 视频“网页全屏”（如 B 站网页全屏）同样自动隐藏
- **全站生效**：在顶层窗口与 iframe 中统一拦截，SPA 动态加载的链接同样适用；选项跨标签页实时同步
- **零网络请求**：所有配置仅保存在本地油猴存储中，脚本不访问任何网络服务

## 安装方法

### 前置条件

先在浏览器中安装 Tampermonkey 扩展（支持 Chrome、Edge、Firefox、Safari 等）。

### 方式一：一键安装（推荐）

确保 Tampermonkey 已启用，直接点击下面的链接：

**[点此安装链接打开方式控制器](https://raw.githubusercontent.com/gaio-x/link-open-controller/main/link-open-controller.user.js)**

Tampermonkey 会自动识别 `.user.js` 文件并弹出安装页，点击“安装”即可。

### 方式二：手动安装

1. 打开 Tampermonkey 管理面板 → “实用工具”
2. 在“从 URL 安装”中粘贴：
   ```
   https://raw.githubusercontent.com/gaio-x/link-open-controller/main/link-open-controller.user.js
   ```
3. 点击“安装”并确认；或在“管理脚本 → 新建脚本”中粘贴本仓库 `link-open-controller.user.js` 的全部内容后保存

> 中国大陆访问 `raw.githubusercontent.com` 受阻时，可使用镜像站（如将链接前缀替换为 `https://ghfast.top/`），或下载本仓库的 `.user.js` 文件后拖入 Tampermonkey 管理面板完成安装。

## 使用说明

| 操作 | 说明 |
| --- | --- |
| 点击悬浮按钮 | 展开 / 收起设置气泡 |
| 拖动悬浮按钮 | 移动到任意位置（自动保持在屏幕内） |
| 模式按钮 `无` / `新窗并切换` / `新窗不切换` | 切换链接打开模式，立即生效 |
| 图标网格 | 点击缩略图更换悬浮按钮皮肤 |
| 透明度滑条 | 调整气泡面板背景不透明度（0.2–1） |
| 尺寸滑条 | 调整悬浮按钮大小（40–120px） |

- 所有设置自动保存，无需手动确认。
- 脚本在 `file://` 本地页面也可运行（需在扩展中允许 Tampermonkey 访问文件网址）。

## 数据与隐私

- 仅使用 `GM_getValue` / `GM_setValue` 在本地保存配置（模式、位置、皮肤、透明度、尺寸），不收集、不上传任何数据。
- 使用 `GM_openInTab` 打开新标签页，前后台行为由浏览器扩展可靠保证。

## 常见问题

**Q：安装后看不到悬浮按钮？**
A：确认脚本处于启用状态并刷新页面；若页面存在浏览器全屏或视频网页全屏，按钮会自动隐藏，退出全屏即可恢复。

**Q：设置在 iframe 里不生效？**
A：脚本会在所有框架中拦截链接，并通过共享存储实时同步选项，无需额外配置。

**Q：如何更新脚本？**
A：在 Tampermonkey 中开启“检查更新”，或重新点击安装链接覆盖安装；更新不会清除已有配置。
